# Pianificatore turni

Web app per creare e controllare gli orari settimanali di un ristorante (crew e hospitality):
regole contrattuali, coperture per fascia, aperture e chiusure, doppi, ferie, previsioni (Crew Hours),
generatore automatico e "Risolvi problemi".

- Funziona interamente nel browser: i dati restano **solo nel browser** di chi la usa (nessun server).
- Per spostare i dati su un altro dispositivo: **Regole → Dati → Esporta / Importa dati**.
- Nessun dato personale è incluso in questo repository.
